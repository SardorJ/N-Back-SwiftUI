# Reflection

One thing that surprised me about working with AI was:

It caught the context of the assignment very well and got the core parts right, which was impressive. It thought for a while, so I would guess it tried what worked and what didn't work, then iterated until it got it right.
What also surprised me was how good it was at making the assignment, but it did not really think about the user's case, as in some UX parts. Like the blinking, which it missed. I did not understand if it was the same place again or if it lagged. I understood it once I saw the step counter go up.

One thing I would do differently next time is:

The thing I would do differently would probably be to make sure it had good UX, so the user won't be confused by some design choices or by how it worked. I would also not use the Xcode UI for agents, because it was difficult to understand what was happening, and it was not a nice look or easy to work with. It would be nice to have something like Cursor, where if I did not understand some parts I could look closely at the code and get a clearer picture, but the Xcode UI is really bad and difficult to use.
